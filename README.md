# مدیریت سرویس مدرسه

Android Native / Kotlin / SQLite — آفلاین و فارسی.

## نسخه ۱.۳.۰

### تغییرات مهم
- **حذف محدودیت ۸ دانش‌آموز**: ارتفاع ثابت جدول حذف شد؛ حداقل ۶۰ دانش‌آموز پشتیبانی می‌شود.
- فرم افزودن دانش‌آموز با دکمه‌های «ثبت و افزودن نفر بعدی» و «ثبت و بستن».
- سال تحصیلی قابل انتخاب (مثلاً ۱۴۰۵–۱۴۰۶) با ماه‌های مهر تا شهریور.
- انتخاب ماه فعال؛ آمار و جدول مطابق ماه/سال انتخاب‌شده به‌روز می‌شوند.
- جدول کامل دانش‌آموزان با ۱۲ ستون ماه + امکان ثبت/لغو پرداخت با لمس.
- تاریخ پرداخت شمسی بدون ساعت.
- شناسه پرداخت: Student ID + Academic Year + Persian Year + Persian Month.
- داشبورد با آمار پرداخت‌شده / نشده / مبلغ دریافتی / مانده.
- منو: دانش‌آموزان، افزودن، پشتیبان‌گیری، بازیابی، گزارش ماهانه، تنظیمات.
- گزارش ماهانه با نام، مبلغ، وضعیت و تاریخ پرداخت.
- پشتیبان‌گیری خودکار محلی + Backup/Restore JSON با اعتبارسنجی.
- UI فارسی RTL؛ اطلاعات طراح حفظ شده.
